### [local-workbench](https://github.com/im-fan/local-workbench)

让操作远端容器像操作本地文件一样编辑，无需 SSH。文件浏览、文本编辑和 Shell 在同一个页面，只使用 Node.js 标准库。

```bash
./start.sh start
```

### [py-tool](https://github.com/im-fan/py-tool)
